# Ironworks

One of each thing a mod can add, with its own art:

- **Skimmer Hover Tank** — a fresh unit (no `extends`), drawn from
  `sprites/hover.png`: one up-facing image the game bakes into 24 headings.
- **Bunker** — a defended building drawn from a two-frame strip,
  `sprites/bunker.png`, placed by the engineer.
- **Fusion Plant** — a fourth level for the power plant line: `power3` gains an
  Upgrade button that turns it into this def.

The sheets are plain pixel art with the faction colour in magenta; the game
recolours it per player.
